# Product Roadmap

Version **1.0** is feature complete. The product ships as a polished personal reading companion with library management, reading insights, sharing and administration already in place.

Future development will be driven primarily by real-world usage rather than speculative features. New work should earn its place by solving problems readers actually encounter.

---

## Version 1.1

**Quality of Life**

Focused refinements rather than new product surface area:

- UI polish across library, dashboard and share views
- Performance improvements for larger personal libraries
- Accessibility improvements
- Mobile refinements
- Better loading states for metadata search and media
- Small workflow improvements informed by day-to-day use

---

## Future Ideas

Ideas under consideration — not commitments:

- Reading Memories
- Mobile application
- Reading recommendations
- Collection improvements
- Additional export formats

---

## Guiding Principles

- Preserve production data.
- Keep the product simple.
- Prioritise reader experience.
- Prefer polish over feature bloat.
- Build features only when they solve real user problems.
